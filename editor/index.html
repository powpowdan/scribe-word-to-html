Scribe: Word to HTML modular editor

Paste Word content. Edit in Live or Code. Copy clean Canada.ca HTML.

Import

Converted by mammoth. Paste (below) is the primary path.

How it works

  1. Paste Word content into the Live view (Ctrl+V). It is cleaned automatically.
  2. Edit in Live (visual) or Code (HTML). They sync on blur.
  3. Copy HTML — placeholders become <!-- image: ... --> comments in the output.
Double-click opens it. No server or build step needed — this editor loads entirely from local files. Work offline.
