## Purpose

Lets the author choose between English and French as the language governing the publishing text that Scribe's commands produce (On-this-page, Table-of-contents, footnotes, and similar generated markup), so a single tool can produce either official-language output.

## ADDED Requirements

### Requirement: Language switch governs command output language

The editor SHALL provide a language switch with at least two states: English and French. The selected language SHALL determine the language of publishing text inserted by commands, without changing the user-interface chrome of the editor itself.

#### Scenario: Generated text follows the selected language

- **WHEN** the language switch is set to French and the user runs a command that inserts an On-this-page section
- **THEN** the inserted section's text is in French

#### Scenario: Switching does not change editor chrome

- **WHEN** the user toggles the language switch from English to French
- **THEN** the editor's own button labels and panel headings remain in their original language

### Requirement: Language selection persists across sessions

The selected language SHALL persist across editor reloads, so the user does not have to re-select it each time.

#### Scenario: Choice remembered on reload

- **WHEN** the user sets the switch to French and reloads the editor
- **THEN** the switch is still set to French on the reloaded editor

### Requirement: Language selection applies to subsequently generated content only

Changing the language SHALL NOT retroactively rewrite publishing text that commands have already inserted; it SHALL apply only to content generated by commands run after the change.

#### Scenario: Existing generated text is left intact on switch

- **WHEN** the user inserts an On-this-page section in English and then switches the language to French
- **THEN** the previously inserted English On-this-page text is unchanged
