# Scribe: Word to HTML

Convert Word documents into clean Canada.ca-ready HTML.

![Scribe: Word to HTML](1.JPG)

## Author / Creator

**Daniel Brown, IS-03, FedDev Ontario**

## Usage

Scribe is a single self-contained HTML file — no build step or server required.

1. Open `word-to-html.html` in any modern web browser (Chrome, Edge, Firefox, etc.).
2. Paste or load your Word content.
3. Copy the generated clean HTML.

> **Note:** Bootstrap and Font Awesome are loaded via CDN, so an internet connection is required on first load.
